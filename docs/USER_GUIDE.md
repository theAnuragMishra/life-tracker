# Using Gather

The same guide is available inside the app at **`/guide`**, including before sign-in. A five-step walkthrough opens on first use and can be replayed from the sidebar or Settings & data.

## A first five-minute session

1. Use **Add something** to capture a few thoughts. Only a title is required. Save without choosing a kind to send it to Inbox.
2. Open **Inbox** and choose what each thought represents: an Action, Practice, Goal, or Interest.
3. Decide whether each item is **Active** (attention now) or **Later** (keep the possibility). Selecting a kind clears “Keep in Inbox”; check it again if you’re not done clarifying.
4. Add notes, a life area, links, or a date only when useful.
5. Return to **Focus** and pick one thing to move forward.

## Four kinds

| Kind     | Use it for                    | How to progress                                                    |
| -------- | ----------------------------- | ------------------------------------------------------------------ |
| Action   | A one-time task               | Click its completion circle                                        |
| Practice | Something you return to       | Record check-ins or amounts                                        |
| Goal     | A desired outcome             | Link actions/practices/interests, then open its steps              |
| Interest | Something you want to explore | Open its resources, explore it, and eventually finish or evolve it |

A kind can change as your intention changes. A goal with linked items must have those items moved before changing its kind. Goals are one level deep in this version.

## Focus

- **Needs attention:** deadlines and intended work dates that have arrived.
- **Your practices:** practices relevant to the current local day or week.
- **Worth picking up:** up to four active possibilities, with a reason for each suggestion. Pins rank first, then arrived revisit dates, then older captures. Future work dates hold suggestions back.

Use a suggestion's three-dot button to hide it for today. It stays in Overview. Completed items remain available in Overview and Search.

## Practices

Choose daily, selected weekdays, days per week, or flexible. Weekly targets count distinct days, Monday–Sunday. Flexible practices remain available without a schedule penalty.

**Finish today** logs the remaining amount needed for today's target. For partial progress, open the practice and use **Record progress**. Weekly **Check in** records one practice day. A second check-in on the same day does not add another day. Use **Undo check-in** to remove an incorrect entry.

Earlier check-ins remain when the rhythm changes. Rule changes apply from today; multiple edits on one day replace that day's rule. The detail view displays 14 recent entries; exports include the full history. A missed day never becomes an overdue task copy.

## Dates

- **Deadline:** must finish by this date.
- **Work on:** intend to give this attention on this date.
- **Revisit on:** consider this again in Review, especially for Later items.

Dates are day-level, not specific hours. Settings controls your timezone. Old check-ins keep their original local dates when your timezone changes.

## Overview and Review

Overview groups clarified items by life area. Filter by kind, life area, or commitment, including Later, Completed, and Archived. Open an item and change its commitment to restore or archive it. Unsorted captures remain in Inbox.

Review surfaces Inbox thoughts, arrived revisit dates, overdue commitments, goals without an active supporting step, and active items unchanged for two weeks. Keep an item active, edit it, set it aside until next week, or archive it. Each decision saves immediately. There is no requirement to finish a review in one session.

## Find, export, and get help

Press **N** to capture and **/** to search when you aren't typing in another field. Search includes notes and links across all states. Settings & data contains timezone preferences, walkthrough replay, sign-out in cloud mode, and a JSON export. Importing that file is not currently supported.

Cloud data persists in your account. Reopen or reload to pick up another device's changes. Cloud mode needs an internet connection and doesn't queue offline writes. Failed saves show a message.

The labeled local demo uses this browser's storage, has no account, and doesn't sync. Clearing storage removes demo data. Connecting Supabase starts a separate empty account; demo records are not automatically uploaded. Export anything you want to keep.
